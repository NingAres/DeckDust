# 收藏统计

- 入口位于“我的套牌”下方，标题为“收藏统计”，预览地址使用 `#collection-stats`。
- 延续现有深色木纹导航、羊皮纸数据面板、铜金边框，复用根目录的品质图标与卡包素材。
- 当前为界面预览，所有数字及模式归属均来自独立的 `src/collection-stats/demo.js` 示例，不读取或保存真实收藏，不调用统计或同步接口。
- 顶部四项指标：任一品质收藏种类、普通版本收藏种类、金色版本收藏种类、任一品质尚未拥有种类。
- 中间环图展示已拥有卡牌的稀有度构成；右侧条形图展示每种稀有度的已拥有 / 可收藏种类。
- 下方柱状图以统一 0–100% 比例比较各扩展包，明细表并列展示全部品质、普通卡、金卡、缺失种类及当前品质完成度。
- 模式切换重置扩展包选择；选择扩展包或点击柱状图、表格名称联动顶部指标与稀有度分布；品质筛选联动两个图表与明细完成度；发行顺序、完成度、缺失种类排序同时作用于柱状图和表格。
- “普通卡”表示非金色版本，“普通”稀有度单独标注。全部品质按卡牌种类去重，当前以至少拥有一张为口径，不表示构筑满编。
- 后续接入真实数据时，另行确定可收藏分母、特殊品质适用范围、核心与免费卡处理和满编口径，遵守项目功能规则。
- 窄窗口采用双列指标、单列图表、可横向滚动的明细表；文字和数字始终保留，不只依赖颜色传达信息。
