# Application icon

`deck-dust.ico` is a multi-resolution Windows conversion of the existing
`assets/brand.svg` Hearthstone-inspired swirl mark. It includes 16, 24, 32, 48,
64, 128 and 256 pixel sizes with transparent backgrounds.

Source: the project's existing vector asset; no new external artwork was added.
This conversion does not grant additional rights to the source artwork or the
Hearthstone brand. Hearthstone belongs to Blizzard Entertainment.

`DeckDust.spec` embeds this icon into the Windows executable. Desktop shortcuts
use the same icon from the packaged `web-dist/assets/app-icons/` directory.
