# UI skin sprites

Crops extracted from the user-selected Deck Dust reference screenshot (1586×992). Text and icons remain live application content.

- `wood-rail.png`: clean dark walnut area from the reference navigation rail.
- `wood-header.png`: text-free walnut grain from the title bar.
- `parchment-wrinkle.png`: wrinkle and fiber parchment material made to match the reference's leather-paper panels.
- `hearthstone-crest.png`: top-left logo plaque cropped from the selected reference image for the navigation rail.
- `monitor-frame.png` and `pity-frame.png`: complete ornamental borders cropped from the reference's matching right-side panels, with the center cleared for live UI content.
- `nav-frame.png`: compact 9-slice frame sprite with a transparent center; selected navigation states are rendered by CSS.
- The navigation logo uses `hearthstone-crest.png`.
- `paper-frame.png`: compact 9-slice sprite for the main parchment panel, extracted from its wood-and-brass border. Its center is transparent.
- `shell-corner-tl.png`, `shell-corner-tr.png` and `shell-corner-bl.png`: outer frame corner ornaments, with the near-black background made transparent.
- `pack-tavern-vignette.webp`: original AI-generated transparent fantasy card-game vignette used decoratively below the pack pity panel. It is not Blizzard or Hearthstone character artwork; the card-back motif is generic and contains no text or logo.

All assets are source files under the root `assets/` tree.
These runtime sprites are included in source checkouts and application builds. Hearthstone imagery in the supplied screenshot belongs to Blizzard Entertainment and its licensors.
