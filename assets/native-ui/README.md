# Hearthstone UI reference assets

Current collection UI: Druid, Death Knight, Priest and Neutral use SVG silhouettes extracted from the owner's explicitly identified reference positions 3, 1, 7 and 12. See `extracted-class-symbols/README.md` for the source, crop coordinates and mapping. No newly generated artwork is used for these replacements.

The eight other class marks use monochrome artwork from [HearthSim/hs-icons](https://github.com/HearthSim/hs-icons), with its CC0 license and source README kept in `hearthsim-class-icons/`. CSS builds the surrounding controls. `extracted/set-book-emblem.png` and the mana crystals in `../mana-crystals/` came from the owner-supplied collection screenshot. Unused reference crops, duplicate icon sets and extraction intermediates were removed on 2026-10-27. Derived Hearthstone artwork remains subject to Blizzard's terms.
