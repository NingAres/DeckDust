# Contributing

Thanks for helping improve Deck Dust. Issues and pull requests are welcome.

## Before opening a pull request

- Describe the user-facing problem and the behavior you changed.
- Keep personal collection data, SQLite databases, credentials, cookies, local paths, and generated build output out of commits.
- Use a temporary data directory for any manual verification; never run checks against a user's active database.
- Run `npm run build` for frontend changes. Run relevant existing checks when changing behavior.
- Keep UI text and documentation clear about limitations and third-party data sources.

## Project notes

This project is created and maintained with AI assistance. AI-generated contributions should be reviewed by a human before merging. Do not include private user data in prompts, issues, screenshots, or pull requests.
